# Бот для продажу фонограм

PHP 8.1+ (розширення `curl`, `pdo_mysql`) і MySQL 5.7+ / MariaDB 10.3+, без сторонніх залежностей. Фонограми, ціни, реквізити й тексти зберігаються в **Contentful**, а покупці й замовлення — у **MySQL**.

## Як це працює

1. Покупець натискає `/start`, і бот просить поділитися номером телефону. Номер на `+380` означає ціни в гривнях, будь-який інший номер або «Пропустити» означає ціни в доларах.
   > Визначити країну за IP у Telegram-боті неможливо: Telegram не передає боту IP користувача.
2. Покупець обирає фонограму, натискає «Купити» і бачить реквізити, суму та номер замовлення.
3. Після оплати покупець натискає «Я оплатив(ла)», і всім адмінам з `ADMIN_IDS` приходить запит із кнопками «Підтвердити» та «Відхилити».
4. Якщо адмін натискає «Підтвердити», бот бере файл із Contentful і надсилає його покупцю. Якщо «Відхилити», покупець отримує повідомлення з контактом підтримки.
5. Куплені фонограми можна отримати повторно через «🧾 Мої покупки».

Команди для адмінів:
- `/orders` — запити, що чекають на підтвердження;
- `/refresh` — перечитати дані з Contentful просто зараз.

## Формати: MP3 і WAV

Після підтвердження оплати покупець обирає формат. Обидва формати входять у покупку, і завантажувати їх можна будь-коли через «🧾 Мої покупки».

- **MP3** зберігається в Contentful, у полі «MP3-файл» фонограми. Безплатний Contentful приймає файли до 50 МБ.
- **WAV** зберігається на сервері в папці `wav/`, у корені проєкту поруч із `public/`, з тією самою назвою, що й MP3, але з розширенням `.wav`. Наприклад, `ЯК ПІЗНАТИ ТЕБЕ ( МІНУС+БЕК ).mp3` → `wav/ЯК ПІЗНАТИ ТЕБЕ ( МІНУС+БЕК ).wav`. Підійде й назва фонограми з `.wav`. Регістр і пробіли біля дужок не враховуються. Якщо ім'я зовсім інше, впишіть його в поле «Ім'я WAV-файлу на сервері».
- WAV до 50 МБ бот надсилає файлом у Telegram. Більші (ліміт ботів Telegram — 50 МБ) він видає посиланням `download.php`, яке діє 24 години, прив'язане до покупця й перевіряє покупку. Посилання підтримує докачування.
- Кнопка WAV з'являється лише тоді, коли файл є на сервері. Які WAV бракує, покаже `php bin/check-tracks.php` або команда `/refresh` в боті.

## Що де редагується

| Contentful (часто змінюється) | `.env` (рідко змінюється / секрети) |
|---|---|
| Фонограми: назва, файл, опис, власна ціна, порядок, «зняти з продажу» | Токен бота, секрети вебхуків |
| Ціни за замовчуванням, реквізити, контакт підтримки, привітання | Ключі Contentful, `ADMIN_IDS` |

`ADMIN_IDS` навмисно зберігаються в `.env`: інакше будь-хто з доступом до Contentful міг би призначити себе тим, хто підтверджує оплати.

## Встановлення

1. **Contentful.** Створіть простір. У Settings → API keys створіть ключ і скопіюйте Space ID та Content Delivery API token. У Settings → CMA tokens створіть Management token.
2. **MySQL.** Створіть порожню базу й користувача, таблиці бот створить сам при першому запиті:
   ```sql
   CREATE DATABASE yohanan_bot CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   CREATE USER 'yohanan_bot'@'localhost' IDENTIFIED BY 'надійний-пароль';
   GRANT ALL PRIVILEGES ON yohanan_bot.* TO 'yohanan_bot'@'localhost';
   ```
3. **`.env`.** Виконайте `cp .env.example .env` і заповніть токен бота, `ADMIN_IDS`, дані Contentful і доступ до MySQL (`DB_*`).
4. **Структура в Contentful.** Скрипт створить типи контенту «Фонограма» й «Налаштування бота» з підказками під полями, а також чернетку налаштувань:
   ```bash
   php bin/contentful-setup.php
   ```
   Після цього `CONTENTFUL_MANAGEMENT_TOKEN` можна видалити з `.env`.
5. **Наповнення.** У Contentful заповніть реквізити в «Налаштуваннях бота» і натисніть **Publish**. Потім додайте фонограми через Content → Add entry → Фонограма. Опублікувати потрібно і запис, і сам файл.
6. **Перевірка.** Скрипт покаже, що бачить бот:
   ```bash
   php bin/check-tracks.php
   ```

Кожен адмін має один раз натиснути `/start` у боті, інакше бот не зможе надсилати йому запити.

### Сервер

- Document root вебсервера має вказувати на `public/`. Папка `storage/` і файл `.env` не повинні бути доступні з вебу, а `storage/` має бути доступна PHP на запис.
- Потрібен HTTPS. Підключіть webhook Telegram:
  ```bash
  php bin/set-webhook.php https://your-domain.com/webhook.php
  ```
- **Вебхук Contentful** (рекомендовано): без нього зміни з'являються в боті протягом `CONTENTFUL_CACHE_TTL` секунд (за замовчуванням 5 хвилин), з ним одразу. Налаштування: Settings → Webhooks → Add webhook:
  - URL: `https://your-domain.com/contentful-webhook.php`, метод `POST`;
  - Triggers: Entry і Asset — Publish, Unpublish, Delete;
  - Headers: `X-Webhook-Secret` зі значенням `CONTENTFUL_WEBHOOK_SECRET` з `.env`;
  - Payload → Customize: content type `application/json`. ModSecurity на хостингу блокує стандартний `application/vnd.contentful.management.v1+json` і відповідає 403.

### Оновлення коду на сервері

```bash
bash bin/deploy.sh
```

Скрипт перевіряє синтаксис, заливає код через ssh (`.env`, кеш і логи на сервері не перезаписуються) і перевіряє, що бот на сервері бачить Contentful і базу. Сервер, ключ і шлях задаються змінними `SSH_TARGET`, `SSH_KEY`, `REMOTE_DIR`.

### Локально (без HTTPS)

```bash
php bin/poll.php
```

Polling і webhook не працюють одночасно. Якщо бот уже працює на сервері, `poll.php` відмовиться запускатися: з `--force` він вимкне webhook, і після тестів його треба буде знову встановити через `set-webhook.php` на сервері.

### Тестові фонограми

Для розробки без справжніх фонограм:

```bash
php bin/contentful-test-data.php           # 10 коротких мелодій [ТЕСТ] (WAV і M4A, одна знята з продажу)
php bin/contentful-test-data.php --delete  # видалити їх перед запуском для покупців
```

Скрипт працює лише із записами `test-track-N` та файлами `test-audio-N` і справжній контент не зачіпає.

## Варто знати

- **Щоб прибрати фонограму з продажу**, увімкніть «Зняти з продажу», а не знімайте її з публікації і не видаляйте. Інакше ті, хто її вже купив, не зможуть завантажити її повторно.
- Бот може завантажити в Telegram файл розміром до **50 МБ**. Contentful не дасть прикріпити більший файл. Великі WAV краще конвертувати в MP3 320 kbps.
- Файл завантажується в Telegram лише один раз, далі бот надсилає його за `file_id`. Якщо файл у Contentful замінити, бот завантажить його заново автоматично.
- Посилання на файли в Contentful (`assets.ctfassets.net`) публічні, хоч і довгі, тож вгадати їх практично неможливо. Покупці їх не бачать, бо бот надсилає сам файл. Повністю закрити доступ до файлів можна через Embargoed Assets на платних тарифах Contentful.
- Якщо Contentful тимчасово недоступний, бот працює з останньою збереженою копією даних.
- Реквізити й привітання підтримують HTML-розмітку Telegram: `<b>`, `<i>`, `<code>`. Незакритий тег зламає повідомлення, тож після змін варто перевірити бота.
- Логи помилок пишуться у `storage/logs/bot.log`.
- **Бекап:** уся історія продажів зберігається в базі MySQL (`mysqldump yohanan_bot`). Contentful бекапить себе сам.
